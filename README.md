# Kütahya Korsan Taksi

Kütahya korsan taksi yolcusu Altıntaş'taki Zafer Havalimanı'nı kullanır: Kütahya merkezden 45 kilometre, 43 dakika. Terminal Altıntaş ilçesine 9 kilometredir. Batıya doğru yol uzar; Simav 165 kilometreyle havalimanına en uzak ilçedir.

Çini atölyeleri ve çarşı şehir içinde gezilir. Çavdarhisar'daki Aizanoi'de Zeus Tapınağı görülür; Çavdarhisar 84 kilometredir. Simav, Emet ve Gediz'in kaplıca otellerine kür için gidenler çoğunlukla bir haftalığına bırakılır.
